## 📌 Tentang ReSu_

**ReSu_ Studio** adalah aplikasi desktop pemangkas waktu yang dirancang khusus untuk memproses audio hasil generasi AI (Suno AI) menjadi kualitas standar studio rekaman komersil.

Musik hasil AI sering kali menyisakan distorsi frekuensi tinggi (*metallic sizzle*), fase stereo yang kabur, serta kompresi berlumpur. ReSu_ mengotomatisasi seluruh rantai perbaikan audio tersebut menjadi satu klik yang instan dan *sat-set_*.

---

## ✨ Fitur Utama

- 🧹 **Intelligent Noise Sanitizer:** Membersihkan desis, *spectral artifacts*, dan suara logam tanpa mematikan dinamika instrumen.
- 🎚️ **Lossless Studio Mastering:** Dukungan ekspor **WAV 24-bit Studio Master** murni untuk distribusi resmi (Spotify, Apple Music) dan **MP3 320kbps** untuk video (YouTube, TikTok).
- 🔄 **Multi-Format Ingestion:** Memproses file input **WAV, FLAC, M4A, AAC, dan OGG** selain MP3 standar.
- 🎨 **Custom Cover Art & Rights Tagging:** Tanam gambar sampul resolusi tinggi dan metadata hak cipta (ID3 tag) permanen langsung ke dalam file audio.
- 🚀 **Zero Hassle Distribution:** Tersedia versi Windows Installer Wizard resmi serta versi Standalone Portable.

## 📥 Cara Unduh & Menjalankan

1. Kunjungi rilis resmi di [GitHub Releases](https://github.com/rtrwcloud/resu-studio/releases) atau melalui [Dashboard rtrw.cloud](https://rtrw.cloud).
2. Unduh installer:
   - `ReSu Setup.exe` untuk instalasi standar Windows, atau
   - `ReSu Portable.exe` untuk versi siap pakai tanpa instalasi.
3. Jalankan aplikasi dan aktivasi menggunakan akun/lisensi warga dari platform rtrw.cloud.
